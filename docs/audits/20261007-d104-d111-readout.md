### 下降的是什么：盲评研究

只看比率回答不了一个问题：软提示下少掉的引用，是“教训用上了但没标”，还是“本来就没用上”。所以做了一次盲评。

**总体**：opus-5-5、只收到一种提示的会话里，到达过 Edit/Write/MultiEdit/NotebookEdit 的 PreToolUse 块的
（会话, id）对，包括作为行出现的和在 Read→Edit 提醒里点名的，共 118 对（verdict 30 对，ack1+ack2 88 对）。到达编辑
的子集里，verdict 的引用率是 11/30，ack 是 3/88。

**做法**：每一对给出教训原文（从库里按 id 取 title / lesson_learned / narrative）和随后那次编辑的内容。不给组别，
不给是否被引用，用种子固定的随机顺序打乱。两个互相独立的子代理按同一份标准打分：A = 教训的规则或事实约束了
这次编辑改动的内容；B = 同一个文件或领域，但与这次改动无关；C = 不相关或太空泛。**判定规则在任何标签出现之前
写好**（2026-10-07T21:48:25Z）：

1. A 与非 A 的 Cohen's kappa < 0.40 → 研究无效，按 D#111 原定方案回退。
2. 否则，如果 ack 组有 ≥ 10 个 A，且 ack 的召回率 ≤ verdict 召回率的一半 → 回退。
3. 其他情况 → 保留软提示。主判定用“两位都判 A”，“任一位判 A”作为敏感性分析。

**结果**：kappa = 0.710（两位都判 A 10 对，只有评审二判 A 7 对，只有评审一判 A 0 对，都不判 A 101 对）。

| 口径 | 组 | 对数 | A | 引用 | 召回（引用且 A / A） | 精确率（引用且 A / 引用） | 非 A 对的引用率 |
|---|---|---|---|---|---|---|---|
| 主判定（两位都判 A） | verdict | 30 | 1 | 11 | 0/1 | 0/11 [0, 25.9]% | 11/29 = 37.9% |
| | ack | 88 | 9 | 3 | 1/9 = 11.1% | 1/3 | 2/79 = 2.5% |
| 敏感性（任一位判 A） | verdict | 30 | 4 | 11 | 0/4 | 0/11 | 11/26 = 42.3% |
| | ack | 88 | 13 | 3 | 2/13 = 15.4% | 2/3 | 1/75 = 1.3% |

主判定下 ack 只有 9 个 A，不到 10 个 → 规则 3；敏感性口径下 ack 有 13 个 A，召回率 15.4% 高于 verdict 的
0/4 → 也是规则 3。两种口径结论相同：**保留软提示**。

抽查（揭盲后核对原文）：verdict 时期被引用的 I010、I031、I063，两位评审都判 B，原文也确实如此。例如 I063 的教训讲
“共享 marker 的预算和 seen-set 要按写入者分片”，这次编辑只是给 SessionStart 的事件段加了一个开关，却被写成了
“#NN applied”。ack 时期的 I007（CLAUDE_CONFIG_DIR 相对路径）两位都判 A 且遵守了，但没有被引用。

**这说明了什么，没说明什么**：verdict 时期多出来的引用，几乎都落在与编辑无关的教训上；软提示砍掉的主要是这部分。
但软提示下，适用的教训也大多没被引用（召回 1/9 到 2/13）。所以在两种提示下，引用都不是可靠的“采纳”信号，只是
verdict 的噪声更大。评审只看到编辑内容，看不到 agent 的推理；“过程类”教训（比如“先跑测试再下结论”）按这个标准
大多会判成 B。

**引用衰减还剩多少影响**：v3.88.0（fe2934f0）起衰减不再改 `importance`，只影响有上下限的 `citeFactor`
（`clamp(0.4, 3.0, 1 + 0.2·cited_count − 0.25·uncited_streak)`），它在 pretool 选取每个文件的 1–2 条教训时是第二排序键。
本机库里 278 条可注入的教训：`cited_count` 为 0 的 192 条，1–4 的 75 条，5–9 的 10 条，≥10 的 1 条，即 `cited_count ≥ 5`
的只有 11 条（4.0%）；把当前的 `uncited_streak` 算进去，因子 ≥ 2.0 的只有 4 条（复核时 282 条里的 4 条）。verdict
时期留下的高引用数在排序里的分量很小。

差值 2.4 个百分点，聚类自助法 95% 区间 [-0.8, 6.5]；会话级置换 p = 0.21；按会话计（是否有引用）Fisher p = 0.22
（5/19 对 2/22）。线上标尺交叉核对（`--since 2026-09-27T19:00:00Z --by-framing`）：legacy 6/173，factual 2/159，
引用数与上表相同；legacy 多出来的 11 对里有 9 对来自写本文的会话本身（标尺无法排除它）。

两组在两种软提示上并不均衡：legacy 14 个 ack1 会话、6 个 ack2 会话，factual 9 个、13 个。legacy 的 6 次引用全部来自
ack1 会话；只看 ack1，legacy 6/121 对 factual 0/57，只看 ack2，legacy 0/41 对 factual 2/101。所以上面 3.7% 对 1.3%
的点估计有一部分是在比较两种软提示的配比，这进一步说明这组数据分不出两种措辞。

**上一版 p = 0.032 是怎么来的**：它从 v6.16.0 的 tag 时间（2026-09-27T09:59:25Z）开始取，混进了 10 个当时还在用
verdict 提示的 opus-5-5 会话（8 个 verdict、2 个 mixed，共 63 对、7 次引用）。本机那段时间运行的插件还没有 A/B
代码，这 10 个会话**全部**是 legacy 组，于是 legacy 组的 13 次引用里有 7 次来自它们。

**次要指标：模型有没有把召回块“当可疑文本告诉用户”**（hooks 文档担心的情况）。在主线程 assistant 文本里匹配三组
不区分大小写的正则：`prompt[- ]injection|提示注入|注入攻击`；`system-injected|系统注入|hook[- ]injected|injected
(context|text|instruction|block|reminder)`；`PreToolUse recall|recall block|\[mem\]|notes recorded by claude-mem-lite`。
ack 时期 legacy 组 0/20 个会话，factual 组 0/22 个会话（共 2836 段文本）。这把尺子的阳性对照很弱：它在 verdict 时期
35 个 opus-5-5 会话里有 4 个命中，但逐条看，只有一个（“Hook-injected lessons: #91 applied”）是 agent 把注入内容
说给用户；其余三个是维护者的工作文本，引用插件自己的字符串，或在讨论注入攻击的论文。所以 0/20 和 0/22 只说明这些写法没出现，不能证明这种
失败模式不存在。

**决定**：在当前约 2.5% 的基线上，要检出 2 倍的差异（2.5% 对 5%，双侧 α = 0.05、把握度 80%，正态近似），每组约需
900 对；按 ack 时期的积累速度（约每组每天 16 对），不算会话聚类也要将近两个月，算上会更久。预先登记的“置信区间重叠就通过”没有设容忍幅度，在这个样本量下说不出“不行”，所以它判 factual 通过
不能作数。现有措辞没有观察到害处，factual 也没有观察到好处，所以保留现有措辞：默认 legacy，`factual` / `ab` 改为
可选（`lib/recall-framing.mjs`）。`--by-framing` 继续可用。

## 复现

语料每天都在增长，也在缩小：Claude Code 默认删除 30 天前的会话记录，冻结后不到一小时，就有一个 2026-09-07 的
opus-5 会话从磁盘上消失了。opus-5 的会话截止到 2026-09-22，所以大约 2026-10-22 之后，本机语料里就再也看不到
上面那个模型差异了。过几天重跑得到的是另一组数（度量原则 2）；能复现的是方法。下面嵌入的脚本已经重跑核对过：
在两次运行都存在的 221 个会话里，有 220 个结果逐项一致，剩下 1 个是冻结后仍在运行、记录还在增长的会话。D#104 和 D#111 的方向与量级都已用
线上标尺 `citation-live-replay.mjs` 交叉核对（见上文）。统计部分：会话聚类自助法和会话级标签置换检验各 20000 次，
随机种子固定为 12345；盲评材料的打乱种子是 20261007。两项检验的核心代码如下（池化率 = 该组所有会话的引用对数之和 / 注入对数之和）：

```js
let seed = 12345; // LCG; every figure above was produced with this seed
const rnd = () => ((seed = (Math.imul(seed, 1103515245) + 12345) >>> 0) / 2 ** 32);
const pooled = (S, face) => {
  let k = 0, n = 0;
  for (const r of S) { k += r.faces[face].hit.length; n += r.faces[face].inj.length; }
  return k / n;
};
// 95% interval of the pooled-rate difference, resampling SESSIONS with replacement in each arm.
function clusterBootDiff(A, B, face, iters = 20000) {
  const d = [];
  for (let i = 0; i < iters; i++) {
    const a = A.map(() => A[Math.floor(rnd() * A.length)]);
    const b = B.map(() => B[Math.floor(rnd() * B.length)]);
    d.push(pooled(a, face) - pooled(b, face));
  }
  d.sort((x, y) => x - y);
  return [d[Math.floor(0.025 * d.length)], d[Math.floor(0.975 * d.length)]];
}
// Two-sided p: shuffle the arm LABEL across sessions, keep each session's pairs together.
function permTest(A, B, face, iters = 20000) {
  const obs = Math.abs(pooled(A, face) - pooled(B, face));
  const all = [...A, ...B];
  let ge = 0;
  for (let i = 0; i < iters; i++) {
    for (let j = all.length - 1; j > 0; j--) { const k = Math.floor(rnd() * (j + 1)); [all[j], all[k]] = [all[k], all[j]]; }
    if (Math.abs(pooled(all.slice(0, A.length), face) - pooled(all.slice(A.length), face)) >= obs - 1e-12) ge++;
  }
  return (ge + 1) / (iters + 1);
}
```

比值的区间用同样的会话重抽样，取两组池化率之比。（pre-tag 审查用另一个随机数生成器独立重算，所有区间和 p 值都在
随机误差范围内一致。）

分组和计数用下面这个脚本冻结语料（运行方式
`node extract.mjs <repo> <out.json> <要排除的会话 id，逗号分隔>`）：

```js
// One frozen walk over the live transcript corpus for the D#104 / D#111 readouts.
// Shipped extractors for injections and citations; this script adds, per session, the
// PreToolUse directive the session actually RECEIVED (read off the injected text, not a
// date), the main-thread model, and the D#98 dismissal counters.
import { readdirSync, writeFileSync } from 'node:fs';
import { join, basename } from 'node:path';
import { homedir } from 'node:os';

const REPO = process.argv[2];
const OUT = process.argv[3];
const EXCLUDE = new Set((process.argv[4] || '').split(',').filter(Boolean));
const ct = await import(join(REPO, 'lib/citation-tracker.mjs'));
const { readTranscriptEntries } = await import(join(REPO, 'lib/transcript-scan.mjs'));
const { classifyRecallFraming } = await import(join(REPO, 'lib/recall-framing.mjs'));
const DIRECTIVES = [
  ['verdict', "state '#NN applied' or '#NN n/a"],
  ['ack1', 'name its #NN once where you describe that change'],
  ['ack2', 'add its bare tag (#NN) once at the end of the sentence'],
  ['bind', 'quote the edit line that satisfies it'],
];
const root = join(homedir(), '.claude/projects');
const records = [];
for (const d of readdirSync(root)) {
  let names;
  try { names = readdirSync(join(root, d)).filter((n) => n.endsWith('.jsonl')); } catch { continue; }
  for (const n of names) {
    const path = join(root, d, n);
    const session = basename(n, '.jsonl');
    if (EXCLUDE.has(session)) continue;
    const entries = readTranscriptEntries(path);
    let ts = NaN;
    for (const e of entries) { const t = Date.parse(e?.timestamp || ''); if (Number.isFinite(t)) { ts = t; break; } }
    if (!Number.isFinite(ts)) continue;
    const models = {}, directives = {}, framingSeen = new Set(), resp = new Map();
    for (const e of entries) {
      if (e.isSidechain === true) continue;
      if (e.type === 'assistant' && e.message) {
        const m = e.message.model;
        if (m && m !== '<synthetic>') models[m] = (models[m] || 0) + 1;
        if (Array.isArray(e.message.content)) {
          const k = e.requestId || e.message.id || e.uuid;
          let r = resp.get(k); if (!r) resp.set(k, (r = { text: '', tool: false }));
          for (const b of e.message.content) {
            if (b.type === 'tool_use') r.tool = true;
            if (b.type === 'text' && typeof b.text === 'string') r.text += '\n' + b.text;
          }
        }
      }
      if (e.type !== 'attachment') continue;
      const att = e.attachment;
      if (!att || att.type !== 'hook_success' || !att.stdout || !String(att.command || '').includes('pre-tool-recall')) continue;
      let text = att.stdout;
      try { text = JSON.parse(att.stdout)?.hookSpecificOutput?.additionalContext || att.stdout; } catch {}
      for (const [name, mark] of DIRECTIVES) if (text.includes(mark)) directives[name] = (directives[name] || 0) + 1;
      const f = classifyRecallFraming(text);
      if (f) framingSeen.add(f);
    }
    const re = ct.citationIdRe();
    let mentions = 0, dismiss = 0, replies = 0, repliesWithCite = 0, repliesWithDismiss = 0;
    for (const r of resp.values()) {
      if (!r.text.trim()) continue;
      let anyC = false, anyD = false, m;
      re.lastIndex = 0;
      while ((m = re.exec(r.text))) {
        mentions++; anyC = true;
        if (ct.isDismissalAt(r.text, m.index + m[0].length)) { dismiss++; anyD = true; }
      }
      if (!r.tool) { replies++; if (anyC) repliesWithCite++; if (anyD) repliesWithDismiss++; }
    }
    const bySurface = ct.extractInjectedBySurface(path, { mainOnly: true });
    const cited = ct.extractCitationsFromTranscript(path, { mainOnly: true });
    const faces = {};
    for (const [face, set] of Object.entries(bySurface)) {
      const inj = [...set];
      if (inj.length) faces[face] = { inj, hit: inj.filter((id) => cited.has(id)) };
    }
    records.push({
      project: d, session, ts,
      model: Object.entries(models).sort((a, b) => b[1] - a[1])[0]?.[0] || null,
      directives,
      framing: framingSeen.size === 0 ? null : framingSeen.size > 1 ? 'mixed' : [...framingSeen][0],
      mentions, dismiss, replies, repliesWithCite, repliesWithDismiss, faces,
    });
  }
}
writeFileSync(OUT, JSON.stringify({ stamp: new Date().toISOString(), records }));
```
