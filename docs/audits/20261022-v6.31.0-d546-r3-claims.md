# v6.31.0 pre-tag review, round 3: claims (D#546, 8575ac48)

A fresh blind-brief subagent, 2026-10-22, on the whole narrowed repair-db change against `main`.
Outcome: two P1s, both reproduced by the author on SQLite 3.53.4:

- F1: a definition whose DEFAULT literal is garbled, with names intact, passes the column-name check.
  Rows written before the column was added then read the garbled default, and no line says so. In
  the author's no-log run, importance went from 1 to 3 on 300 rows.
- F2: `PRAGMA integrity_check` on a read-only handle does not evaluate CHECK constraints (read-only
  `ok`, read-write `CHECK constraint failed in t`). doctor shows such a store as healthy, and
  repair-db says there is nothing to repair.

The rule registered before round 3 was: a P0/P1 means repair-db does not ship this release and is
not repaired further. So repair-db did not ship in v6.31.0. The safety claims held: in 736 damaged
plants, no refusal changed bytes, the kept copies matched the store as found, the undo commands
worked, and nothing threw. The report follows as delivered; the scripts are in its appendix.

# D#546 repair-db: blind claims review, round 3 (commit 8575ac48)

## Verdict

The safety claims held in every experiment I ran. Across 736 single-damage plants that failed
integrity_check (random bytes, page headers, zeroed pages, lowered cell counts, misdirected and
stale pages; in the main file or the newest log frame), plus targeted cases, I found:

- no refusal that changed the store's bytes;
- no kept copy that differed from the store as found;
- no undo command that failed to restore it;
- no exception or hang;
- no table that lost rows with no line naming it.

What fails is two of the read side's judgments, and some of what the output and README promise:

- **F1, P1.** A definition whose DEFAULT literal is garbled, with its column names intact, passes
  the name check. Every row written before that column was added is then copied with the garbled
  default and no line, even when the main file alone holds the correct definition.
- **F2, P1 under the rubric's doctor clause.** doctor's and repair-db's integrity check runs on
  read-only handles, and there SQLite skips CHECK constraints. A store that `PRAGMA
  integrity_check` fails on a read-write handle (and in the sqlite3 CLI) shows `✓ Database
  integrity: ok`, and repair-db reports "nothing to repair".
- **P2s:**
  - The main-file fill-in fires for tables that lost no row, so rows the log deleted come back
    under a line that says SQLite could not read them.
  - A refused log row is silently replaced by its older main-file copy and is not listed.
  - The schema version is read from the main file alone, so a v49 store is refused as "v48".
  - The README's three limits are not exhaustive.
- **P3s:** wording and comments.

## Claims

**Claim 1. Reads without writing; store and log unchanged before the write-back; refusals leave
them as found: HOLDS.**
- Sweeps (`sweep.mjs`, seeds 7/11/23/31): 736 damaged plants run. 7 refusals, all with main file
  and log byte-identical.
- Targeted refusals were byte-identical too:
  - `e07` (version);
  - `e12` (read-only file);
  - `e18` (a real writer committing during the read: "changed while it was being read");
  - `e21b` (not a database).
- `e09`: the lock probe left main and log byte-identical, both with a damaged frame and with a bad
  log header. With no log it creates an empty one (acknowledged in the code).
- `e03`: I forced the write-back to fail mid-backup with `ulimit -f` (I/O error).
  - Output: "Could not write into …: disk I/O error; the database reads as it did" and "kept byte
    for byte as …".
  - Main file identical. The log grew from 147,322,992 to 147,631,104 bytes (+308,112) of
    uncommitted frames, and the store reads exactly as before (row diff vs truth: none).
  - The output does not say "nothing was written", so this is not a README falsification. It does
    contradict a code comment (claim 11).
- Note: the read-only opens create an empty `-wal` and `-shm` where none existed (`e17a`). No
  content changes.

**Claim 2. Main-file fill-in for a table that lost rows, said per table: HOLDS when a table did

- The same trigger also fires for any single row the fresh file refuses (`e10`).
- Rows the log deletes are routine here: `delete-core.mjs`, `maintain-core.mjs` and

## NOT CHECKED
- A real disk-full (`SQLITE_FULL`) path. I used RLIMIT_FSIZE, which gives an I/O error instead.
- Rollback-journal or hot-journal stores.
- Hook traffic through `withSwapBarrier` during the write-back.
- Page sizes other than 4096.
- reflink filesystems, macOS and Windows.
- `doctor --json`.
- Compounds not run, each SUSPECTED:
  - a table whose only index is structurally broken plus a stale page of that table (likely silent
    row loss);
  - a damaged schema_version page plus a garbled definition (likely a "columns" refusal that blames
    another version);
  - a newer-version store whose schema_version page is unreadable (likely written as v49).

```js
export function walChecksum(buf, s0, s1, be) {
  for (let i = 0; i + 7 < buf.length; i += 8) {
    const a = be ? buf.readUInt32BE(i) : buf.readUInt32LE(i);
    const b = be ? buf.readUInt32BE(i + 4) : buf.readUInt32LE(i + 4);
    s0 = (s0 + a + s1) >>> 0;
    s1 = (s1 + b + s0) >>> 0;
  }
  return [s0, s1];
}

export function walFrames(p) {
  const wal = readFileSync(`${p}-wal`);
  const ps = wal.readUInt32BE(8);
  const frames = [];
  for (let o = 32; o + 24 + ps <= wal.length; o += 24 + ps)
    frames.push({ o, pg: wal.readUInt32BE(o), commit: wal.readUInt32BE(o + 4) });
  return { wal, ps, frames };
}

/** Re-sign the frame chain of a log buffer in place. */
export function resign(wal) {
  const be = wal.readUInt32BE(0) === 0x377f0683;
  const ps = wal.readUInt32BE(8);
  let [s0, s1] = walChecksum(wal.subarray(0, 24), 0, 0, be);
  wal.writeUInt32BE(s0, 24);
  wal.writeUInt32BE(s1, 28);
  for (let o = 32; o + 24 + ps <= wal.length; o += 24 + ps) {
    [s0, s1] = walChecksum(wal.subarray(o, o + 8), s0, s1, be);
    [s0, s1] = walChecksum(wal.subarray(o + 24, o + 24 + ps), s0, s1, be);
    wal.writeUInt32BE(s0, o + 16);
    wal.writeUInt32BE(s1, o + 20);
  }
}

/** Overwrite bytes of the newest log frame of page pg and re-sign. */
export function plantWal(p, pg, offset, bytes) {
  const { wal, ps, frames } = walFrames(p);
  const buf = Buffer.from(wal);
  const target = frames.filter((f) => f.pg === pg).at(-1);
  if (!target) throw new Error(`no frame for page ${pg}`);
  Buffer.from(bytes).copy(buf, target.o + 24 + offset);
  resign(buf);
  writeFileSync(`${p}-wal`, buf);
  rmSync(`${p}-shm`, { force: true });
}

export function plant(p, pageno, offset, bytes, pageSize = 4096) {
  const fd = openSync(p, 'r+');
  try {
    writeSync(fd, Buffer.from(bytes), 0, bytes.length, (pageno - 1) * pageSize + offset);
  } finally {
    closeSync(fd);
  }
}

export function pages(p, name, type = null) {

}

/** Ordinary tables (no FTS virtual/shadow) and their rows as JSON keyed by rowid. */
export function record(p, { readonly = true } = {}) {
  const db = new Database(p, { readonly });
  try {
    const virtual = db
      .prepare(`SELECT name FROM sqlite_master WHERE type='table' AND sql LIKE 'CREATE VIRTUAL TABLE%'`)
      .pluck()
      .all();
    const shadow = (n) => virtual.some((v) => n.startsWith(`${v}_`));
    const out = {};
    for (const t of db.prepare(`SELECT name FROM sqlite_master WHERE type='table'`).pluck().all()) {
      if (virtual.includes(t) || shadow(t)) continue;
      const stmt = db.prepare(`SELECT rowid AS __rowid, * FROM "${t}" ORDER BY rowid`).safeIntegers(true);
      out[t] = new Map(
        stmt.all().map((r) => [String(r.__rowid), JSON.stringify(r, (_, v) => (typeof v === 'bigint' ? `${v}` : v))]),
      );
    }
    return out;
  } finally {
    db.close();
  }
}

/** Per-table diff between two records: rows lost, rows changed, rows added. */
export function diff(before, after) {
  const out = {};
  for (const t of new Set([...Object.keys(before), ...Object.keys(after)])) {
    if (t === 'schema_version') continue;
    const b = before[t] ?? new Map();
    const a = after[t] ?? new Map();
    const lost = [];
    const changed = [];
    const added = [];
    for (const [k, v] of b) {
      if (!a.has(k)) lost.push(k);
      else if (a.get(k) !== v) changed.push(k);
    }
    for (const k of a.keys()) if (!b.has(k)) added.push(k);
    if (lost.length || changed.length || added.length)
      out[t] = { lost: lost.length, changed: changed.length, added: added.length, lostIds: lost.slice(0, 8), changedIds: changed.slice(0, 8), addedIds: added.slice(0, 8) };
  }
  return out;
}

/**
 * Run repair-db on p and judge it: lines, per-table diff against `truth`, tables changed with no
 * line naming them, the kept copy against the store as found, and (optionally) the undo command.
 */
export async function evaluate(p, truth, { opts = {}, undo = true, label = '' } = {}) {
  const dir = dirname(p);
  const before = snap(p);
  const r = await run(p, opts);
  const out = text(r);
  const res = { label, outcome: r.outcome, exitCode: r.exitCode };
  console.log(`\n===== ${label} → ${r.outcome} (exit ${r.exitCode})`);
  console.log(out);
  if (r.outcome === 'refused' || r.outcome === 'healthy') {
    const after = snap(p);
    res.unchanged = after.main === before.main && after.wal === before.wal;
    console.log(`store bytes as found after ${r.outcome}: main ${after.main === before.main}, wal ${after.wal === before.wal}`);
  }
  if (r.aside) {
    const kept = { main: sha(r.aside), wal: sha(`${r.aside}-wal`) };
    res.keptOk = kept.main === before.main && (kept.wal === before.wal || (before.wal === 'absent' && kept.wal === 'absent') );
    console.log(`kept copy equals store as found: main ${kept.main === before.main}, wal ${kept.wal === before.wal} (before wal ${before.wal.slice(0,8)}, kept wal ${kept.wal.slice(0,8)})`);
  }
  if (truth && (r.outcome === 'repaired' || r.outcome === 'unsound')) {
    let after;
    try { after = record(p); } catch (e) { console.log('record after failed', e.message); }
    if (after) {
      const d = diff(truth, after);
      res.diff = d;
      const unnamed = Object.keys(d).filter((t) => !new RegExp(`(^|[\\s(,])${t}[: (]`, 'm').test(r.lines.map((l) => l.text).join('\n')));
      res.unnamed = unnamed;
      console.log('diff vs truth:', JSON.stringify(d));
      console.log('tables changed with no line naming them:', JSON.stringify(unnamed));
    }
    if (undo) {
      const line = r.lines.find((l) => l.text.startsWith('To go back to it'));
      const cmd = line?.text.replace(/^.*?run[^:]*: /, '').replace(/^.*closed: /, '');
      if (cmd) {
        execSync(cmd, { shell: '/bin/bash' });
        const back = snap(p);
        res.undoOk = back.main === before.main && back.wal === before.wal;
        console.log(`undo command restores the store as found: main ${back.main === before.main}, wal ${back.wal === before.wal}`);
      }
    }
  }
  return res;
}

/**
 * A WAL store: `base` observations checkpointed into the main file, then (without checkpoint) the
 * log gets `late` inserts, `deletes` deletions of checkpointed rows and `updates` title updates.
 * The log is kept by copying files before close. Returns { p, truth (with log), mainTruth }.
 */
export function walStoreX(dir, { base = 200, late = 40, deletes = [], updates = [], vacuum = false } = {}) {
  const p = join(dir, DB);
  const db = new Database(p);
  db.pragma('journal_mode = WAL');
  initSchema(db);
  for (const s of ['s1', 's2'])
    db.prepare(
      `INSERT INTO sdk_sessions (content_session_id, memory_session_id, project, started_at, started_at_epoch) VALUES (?, ?, 'p', datetime('now'), 1)`,
    ).run(`c-${s}`, s);
  const ins = (s) =>
    db.prepare(
      `INSERT INTO observations (memory_session_id, project, type, title, narrative, created_at, created_at_epoch) VALUES ('${s}', 'p', 'discovery', ?, ?, datetime('now'), ?)`,
    );
  for (let i = 0; i < base; i++) ins('s1').run(`title ${i} alpha`, `narrative ${i} gamma ${'x'.repeat(i % 50)}`, 1e12 + i);
  db.pragma('wal_checkpoint(TRUNCATE)');
  db.close();
  const pristine = readFileSync(p);
  const raw = new Database(p);
  raw.pragma('wal_autocheckpoint = 0');
  const li = raw.prepare(
    `INSERT INTO observations (memory_session_id, project, type, title, narrative, created_at, created_at_epoch) VALUES ('s2', 'p', 'discovery', ?, ?, datetime('now'), ?)`,
  );
  for (let i = 0; i < late; i++) li.run(`late ${i} zeta`, `late narrative ${i}`, 2e12 + i);
  for (const id of deletes) raw.prepare('DELETE FROM observations WHERE id = ?').run(id);
  for (const id of updates) raw.prepare("UPDATE observations SET title = 'UPDATED IN LOG' WHERE id = ?").run(id);
  if (vacuum) raw.exec('VACUUM');
  const truth = record(p);
  const wal = readFileSync(`${p}-wal`);
  raw.close();
  writeFileSync(p, pristine);
  writeFileSync(`${p}-wal`, wal);
  rmSync(`${p}-shm`, { force: true });
  const alone = join(dir, 'main-alone.db');
  writeFileSync(alone, pristine);
  const mainTruth = record(alone);
  for (const ext of ['', '-wal', '-shm']) rmSync(alone + ext, { force: true });
  return { p, truth, mainTruth };
}
```

```js
// refusals whose store bytes changed, kept copies that differ, and exceptions.
// usage: node sweep.mjs <seed> <n> <where: main|log|mix> [classes]
import * as L from './lib.mjs';
import { readFileSync, writeFileSync, rmSync, statSync } from 'node:fs';

const [seed0 = '1', nArg = '50', whereArg = 'mix', classArg = ''] = process.argv.slice(2);
let s = Number(seed0) >>> 0 || 1;
const rnd = () => {
  s ^= s << 13; s >>>= 0; s ^= s >> 17; s ^= s << 5; s >>>= 0;
  return s / 4294967296;
};
const pick = (a) => a[Math.floor(rnd() * a.length)];
const CLASSES = classArg ? classArg.split(',') : ['bytes', 'bytes', 'header', 'zero', 'cellcount', 'swap', 'stale'];

function fill(db, phase) {
  const now = 1.7e12;
  const sess = db.prepare(
    `INSERT INTO sdk_sessions (content_session_id, memory_session_id, project, started_at, started_at_epoch) VALUES (?, ?, ?, 'x', ?)`,
  );
  const obs = db.prepare(
    `INSERT INTO observations (memory_session_id, project, type, title, subtitle, narrative, facts, concepts, files_modified, importance, lesson_learned, branch, minhash_sig, superseded_at, compressed_into, created_at, created_at_epoch) VALUES (?, ?, ?, ?, ?, ?, '[]', 'c1 c2', ?, ?, ?, ?, ?, ?, ?, 'x', ?)`,
  );
  const prm = db.prepare(
    `INSERT INTO user_prompts (content_session_id, prompt_text, prompt_number, created_at, created_at_epoch, cc_session_id) VALUES (?, ?, ?, 'x', ?, ?)`,
  );
  const sum = db.prepare(
    `INSERT INTO session_summaries (memory_session_id, project, request, learned, completed, created_at, created_at_epoch) VALUES (?, ?, ?, ?, ?, 'x', ?)`,
  );
  const ofile = db.prepare(`INSERT OR IGNORE INTO observation_files (obs_id, filename) VALUES (?, ?)`);
  const ev = db.prepare(
    `INSERT INTO events (project, event_type, title, body, importance, created_at_epoch) VALUES (?, ?, ?, ?, ?, ?)`,
  );
  const dw = db.prepare(
    `INSERT INTO deferred_work (project, title, detail, priority, status, created_at_epoch, closed_by_obs_id) VALUES (?, ?, ?, ?, ?, ?, ?)`,
  );
  const cl = db.prepare(`INSERT OR REPLACE INTO citation_log (project, memory_session_id, resolved_at, injected_n, cited_n) VALUES (?, ?, ?, ?, ?)`);
  const ho = db.prepare(
    `INSERT OR REPLACE INTO session_handoffs (project, type, session_id, working_on, created_at_epoch) VALUES (?, ?, ?, ?, ?)`,
  );
  const sr = db.prepare(
    `INSERT INTO search_runs (project, query, surface, search_mode, client, created_at, created_at_epoch) VALUES (?, ?, 'mcp_search', 'fts', 'cli', 'x', ?)`,
  );
  const sres = db.prepare(
    `INSERT INTO search_results (search_id, source, result_id, returned_rank) VALUES (?, 'obs', ?, ?)`,
  );
  const base = phase === 0 ? 0 : 10000;
  const types = ['decision', 'bugfix', 'feature', 'refactor', 'discovery', 'change'];
  const nS = phase === 0 ? 6 : 2;
  for (let i = 0; i < nS; i++) sess.run(`cs-${base + i}`, `ms-${base + i}`, `proj${i % 3}`, now + base + i);
  const nO = phase === 0 ? 400 : 60;
  for (let i = 0; i < nO; i++) {
    const r = obs.run(
      `ms-${base + (i % nS)}`,
      `proj${i % 3}`,
      types[i % 6],
      `title ${base + i} ${'t'.repeat(i % 40)}`,
      `sub ${i}`,
      `narrative ${base + i} ${'n'.repeat(50 + ((i * 37) % 900))}`,
      JSON.stringify([`src/f${i % 17}.mjs`]),
      1 + (i % 3),
      i % 5 === 0 ? `lesson ${i}` : null,
      i % 7 === 0 ? `br${i % 4}` : null,
      i % 3 === 0 ? `sig${i}` : null,
      i % 11 === 0 ? now + i : null,
      i % 13 === 0 ? 1 : null,
      now + base + i,
    );
    ofile.run(Number(r.lastInsertRowid), `src/f${i % 17}.mjs`);
  }
  const nP = phase === 0 ? 300 : 50;
  for (let i = 0; i < nP; i++)
    prm.run(`cs-${base + (i % nS)}`, `prompt ${base + i} ${'p'.repeat(20 + ((i * 13) % 400))}`, i, now + base + i, i % 2 ? `cc-${i % 5}` : null);
  for (let i = 0; i < (phase === 0 ? 50 : 8); i++)
    sum.run(`ms-${base + (i % nS)}`, `proj${i % 3}`, `req ${i}`, `learned ${'l'.repeat(i * 7)}`, 'done', now + base + i);
  for (let i = 0; i < (phase === 0 ? 300 : 40); i++)
    ev.run(`proj${i % 3}`, pick(['bugfix', 'lesson', 'bug', 'discovery']), `event ${base + i}`, `body ${'b'.repeat((i * 31) % 300)}`, 1 + (i % 3), now + base + i);
  for (let i = 0; i < (phase === 0 ? 40 : 6); i++)
    dw.run(`proj${i % 3}`, `todo ${base + i}`, `detail ${i}`, 1 + (i % 3), ['open', 'done', 'dropped'][i % 3], now + base + i, i % 3 === 1 ? 1 + i : null);
  for (let i = 0; i < (phase === 0 ? 30 : 10); i++) cl.run(`proj${i % 3}`, `ms-${i % 8}`, now + i, i, i % 4);
  for (let i = 0; i < (phase === 0 ? 10 : 4); i++) ho.run(`proj${i % 3}`, 'clear', `s${i % 6}`, `working ${base + i}`, now + base + i);
  for (let i = 0; i < (phase === 0 ? 50 : 10); i++) {
    const r = sr.run(`proj${i % 3}`, `query ${base + i}`, now + base + i);
    for (let k = 0; k < 4; k++) sres.run(Number(r.lastInsertRowid), 1 + ((i * 4 + k) % 400), k);
  }
}

function build(dir, wal) {
  const p = L.join(dir, L.DB);
  const db = new L.Database(p);
  db.pragma('journal_mode = WAL');
  db.pragma('foreign_keys = OFF');
  L.initSchema(db);
  db.pragma('foreign_keys = OFF');
  L.ensureSearchTelemetrySchema(db);
  fill(db, 0);
  db.pragma('wal_checkpoint(TRUNCATE)');
  if (!wal) {
    db.close();
    return { p, truth: L.record(p) };
  }
  db.close();
  const main0 = readFileSync(p);
  const raw = new L.Database(p);
  raw.pragma('wal_autocheckpoint = 0');
  raw.pragma('foreign_keys = OFF');
  fill(raw, 1);
  raw.exec('UPDATE observations SET importance = 3, title = title || \' upd\' WHERE id % 9 = 0');
  raw.exec('DELETE FROM observations WHERE id % 17 = 0 AND id < 300');
  raw.exec('DELETE FROM user_prompts WHERE id % 23 = 0');
  raw.exec("UPDATE deferred_work SET status = 'done' WHERE id % 4 = 0");
  const truth = L.record(p);
  const walBuf = readFileSync(`${p}-wal`);
  raw.close();
  writeFileSync(p, main0);
  writeFileSync(`${p}-wal`, walBuf);
  rmSync(`${p}-shm`, { force: true });
  return { p, truth };
}

function owners(p) {
  const db = new L.Database(p, { readonly: true });
  try {
    return db.prepare('SELECT name, pageno, pagetype FROM dbstat').all();
  } finally {
    db.close();
  }
}

function plantOne(p, wal) {
  const ps = 4096;
  const own = owners(p);
  const frames = wal ? L.walFrames(p) : null;
  const inLog = wal ? new Set(frames.frames.map((f) => f.pg)) : new Set();
  const cls = pick(CLASSES);
  const candidates = own.filter((o) => (wal ? inLog.has(o.pageno) : true));
  const tgt = pick(candidates);
  const pg = tgt.pageno;
  const hdr = pg === 1 ? 100 : 0;
  let info = { cls, pg, owner: tgt.name, type: tgt.pagetype };
  const write = (offset, bytes) => (wal ? L.plantWal(p, pg, offset, bytes) : L.plant(p, pg, offset, bytes));
  const current = () => {
    if (!wal) return readFileSync(p).subarray((pg - 1) * ps, pg * ps);
    const f = frames.frames.filter((x) => x.pg === pg).at(-1);
    return frames.wal.subarray(f.o + 24, f.o + 24 + ps);
  };
  if (cls === 'bytes') {
    const len = 1 + Math.floor(rnd() * 8);
    const off = Math.floor(rnd() * (ps - len));
    write(off, Array.from({ length: len }, () => Math.floor(rnd() * 256)));
    info = { ...info, off, len };
  } else if (cls === 'header') {
    const off = hdr + Math.floor(rnd() * 8);
    write(off, [Math.floor(rnd() * 256)]);
    info = { ...info, off };
  } else if (cls === 'zero') {
    write(0, Buffer.alloc(ps));
  } else if (cls === 'cellcount') {
    const cur = current();
    const n = cur.readUInt16BE(hdr + 3);
    const nn = Math.max(0, n - 1 - Math.floor(rnd() * 3));
    write(hdr + 3, [nn >> 8, nn & 255]);
    info = { ...info, from: n, to: nn };
  } else if (cls === 'swap') {
    const other = pick(own.filter((o) => o.pageno !== pg));
    const src = wal
      ? (() => {
          const f = frames.frames.filter((x) => x.pg === other.pageno).at(-1);
          return f ? frames.wal.subarray(f.o + 24, f.o + 24 + ps) : readFileSync(p).subarray((other.pageno - 1) * ps, other.pageno * ps);
        })()
      : readFileSync(p).subarray((other.pageno - 1) * ps, other.pageno * ps);
    write(0, Buffer.from(src));
    info = { ...info, from: other.pageno, fromOwner: other.name };
  } else if (cls === 'stale') {
    // A lost write: the page's newest version replaced by an older one (previous log frame, or
    // the main file's copy).
    let older;
    if (wal) {
      const fs = frames.frames.filter((x) => x.pg === pg);
      older = fs.length > 1 ? frames.wal.subarray(fs.at(-2).o + 24, fs.at(-2).o + 24 + ps) : readFileSync(p).subarray((pg - 1) * ps, pg * ps);
    } else older = null;
    if (!older) return plantOne(p, wal);
    write(0, Buffer.from(older));
  }
  return info;
}

const N = Number(nArg);
const results = { refusals: [], total: 0, outcomes: {}, unnamed: [], refusedChanged: [], keptBad: [], undoBad: [], threw: [], unsoundAfter: [], slow: [] };
for (let i = 0; i < N; i++) {
  const wal = whereArg === 'mix' ? rnd() < 0.5 : whereArg === 'log';
  const dir = L.newDir(`sw${seed0}-${i}`);
  const { p, truth } = build(dir, wal);
  let info;
  try {
    info = plantOne(p, wal);
  } catch (e) {
    info = { plantError: e.message };
  }
  const integ = L.checkIntegrity(p);
  if (integ.ok) {
    results.outcomes.cleanIntegrity = (results.outcomes.cleanIntegrity ?? 0) + 1;
    rmSync(dir, { recursive: true, force: true });
    continue;
  }
  results.total++;
  const before = L.snap(p);
  const t0 = Date.now();
  let r;
  try {
    r = await L.run(p);
  } catch (e) {
    results.threw.push({ i, wal, info, e: e.stack });
    continue;
  }
  const ms = Date.now() - t0;
  if (ms > 20000) results.slow.push({ i, ms, info });
  results.outcomes[r.outcome] = (results.outcomes[r.outcome] ?? 0) + 1;
  const txt = r.lines.map((l) => l.text).join('\n');
  if (r.outcome === 'refused') {
    results.refusals.push({ i, wal, info, lines: r.lines.map((l) => `[${l.level}] ${l.text}`) });
    const after = L.snap(p);
    const nothing = /Nothing was written|the database is as it was|reads as it did/.test(txt);
    if ((after.main !== before.main || (after.wal !== before.wal && !(before.wal === 'absent'))) && nothing)
      results.refusedChanged.push({ i, wal, info, txt });
  }
  if (r.aside) {
    const okMain = L.sha(r.aside) === before.main;
    const kw = L.sha(`${r.aside}-wal`);
    const okWal = kw === before.wal || (kw === 'absent' && (before.wal === 'absent' || statSync(`${p}-wal`, { throwIfNoEntry: false }) === undefined || before.wal === 'da39a3ee5e6b4b0d3255bfef95601890afd80709'));
    if (!okMain || !okWal) results.keptBad.push({ i, wal, info, okMain, okWal });
  }
  if (r.outcome === 'repaired' || r.outcome === 'unsound') {
    if (r.outcome === 'unsound') results.unsoundAfter.push({ i, wal, info, txt });
    let after;
    try {
      after = L.record(p);
    } catch (e) {
      results.unsoundAfter.push({ i, wal, info, recordError: e.message });
    }
    if (after) {
      const d = L.diff(truth, after);
      const masterWarn = /Part of its list of tables could not be read/.test(txt);
      for (const [t, dd] of Object.entries(d)) {
        const named = new RegExp(`(^|[\\s(,])${t}[: (]`, 'm').test(txt);
        if (!named)
          results.unnamed.push({ i, wal, t, ...dd, masterWarn, info, txt: txt.slice(0, 1500) });
      }
    }
  }
  rmSync(dir, { recursive: true, force: true });
}
const summary = { ...results, refusals: results.refusals.length, unnamed: results.unnamed.length, refusedChanged: results.refusedChanged.length, keptBad: results.keptBad.length, threw: results.threw.length, unsoundAfter: results.unsoundAfter.length };
console.log(JSON.stringify(summary));
writeFileSync(`${L.SB}/work/sweep-${seed0}-${whereArg}-${classArg || 'all'}.json`, JSON.stringify(results, null, 1));
```
