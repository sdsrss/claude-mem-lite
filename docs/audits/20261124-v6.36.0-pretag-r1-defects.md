- Reach: `--project .` / `current` appear on this machine's 130 transcripts essentially only in this repo's own

### F5 · P3 · constructed, predates 6.36.0 — `.` is spelled as text, then re-resolved as an explicit name
- Where: `mem-cli.mjs:4456-4461` substitutes `cliWriteProject().project`. The command then resolves it like a typed

  - Cosmetic: `activity --project=. save …` reports `Unknown activity subcommand: --project=-home-x-proj--memory`,
    the substituted value.
