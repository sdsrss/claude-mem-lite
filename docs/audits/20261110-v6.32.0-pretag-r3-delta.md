## Q3 — Claude Code's limit

Claude Code 2.1.322 bundle: `PY=4194304` (offset 294675416) used by the instruction-file reader `tJe` → `OT(w,e,PY,…)` with the message
"[CLAUDE.md] skipping …: not a regular file or exceeds ${PY} byte limit"; the verdict function `Pe` skips when `!i.isFile()||i.size>n` —
strictly greater. A batched path skips on `s.totalBytes>PY`, also strictly greater. Rules files (`eAe`) go through the same per-file reader
(`Vq`). Real runs confirm: 4,194,304 bytes loads, 4,194,305 is skipped. The plugin's `st.size > 4194304` matches (value and comparison).

the plugin does not (F1). Separately, `loadMarkdownFilesFromDir` (commands/agents) uses 1,048,576 (`uIt`), not instruction files.
