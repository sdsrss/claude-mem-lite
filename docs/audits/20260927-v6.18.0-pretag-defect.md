## P2

### P2-1 Flattening runs BEFORE scrubbing and rewrites characters inside secret values, so some secrets that the raw reply would lose get stored
lib/fast-summary.mjs:273-274 (`flattenReply(report.tail)` then `clean(...)`), with flattenReply at :85-97.
- flattenReply deletes `__` and turns `|` into a space. Both characters occur inside real credential values, and after the change the scrub patterns no longer match.
- Probe (writeStopSummary on a no-report tail; the stored `completed` is shown):
  - Google key with `__`: raw `scrubSecrets('key AIza…Qx__7Rt…')` gives `key ***`. The stored row is `"Use key AIzaSyD4k9Lm2Qx7Rt5Vb8Nc1Hj6Wp0Zf3GaQ in config."`. `AIza[..]{35}` fails on 33 chars, so the key is stored minus 2 chars.
  - Password with `|`: raw `password=hunter2|Zq9xw7Lk` gives `password=***`. The stored row is `"password=*** Zq9xw7Lk ok"`: everything after the pipe leaks.
- The "scrub before truncate" guarantee holds: a ghp_ token straddling position 95 is stored as `***`. What breaks is scrub-before-TRANSFORM, which is new: the report path does not flatten.
- The stored value is injected into SessionStart and the handoff.
- Fix shape: scrub the raw reply first (`scrubRecord` on report.tail), then flatten, then clean/truncate.

### P2-2 A Not-done-only (or Failed-only) final reply is stored and shown as `Completed:`
lib/fast-summary.mjs:271-273. The floor is taken whenever `!done`, including when `notDone` is set.
- The contract (CHANGELOG, README "Upgrading to 6.18.0", the commit message and tasks/specs/d121-tail-floor.md §goal) says the floor applies when the reply has "no Done / Not done report". The code comment at :271-272 deliberately does the opposite.
- Rendered by buildSummaryLines + neutralize (probe4):
  ```
  Completed: Not done: the schema migration — blocked on AUTH. I stopped before touching the DB.
  Remaining: the schema migration — blocked on AUTH.
  ```
- Failed-only reply (probe1): `completed = "Failed: npm test exits 1 on tests/x.test.mjs. Uncertain: whether CI matches."`, notes `donetail leftother`.
- The next session is told that an unfinished or failed item was completed. Before 6.18 this slot showed titles or was empty.
- No test covers a Not-done-only turn together with the tail.
