## P1

### P1-1 cut-off PEM 模式的 RFC 1421 头部行分支对构造输入呈二次方耗时（相对 v6.19.0 是回归）
- 位置：`secret-scrub.mjs:217`，分支 `(?:Proc-Type|DEK-Info|Version|Comment|Hash|Charset):[^\r\n\\]*` 后接 `[ \t]*(?=\r?\n|\\[rn]|"|$)`。
- 机制：
  - `[^\r\n\\]*` 本身就包含空格和 tab，后面的 `[ \t]*` 又能吃同一段空白。
  - 行尾如果不是被接受的结束符，引擎会把 `[^\r\n\\]*` 逐字符回退；每回退一个位置，`[ \t]*` 都要重新扫完剩下的空白串。代价 O(k²)，k 是空白串长度。
  - 能触发的停止字符：
    - 6b4dab2 之后，任何后面不是 r/n 的反斜杠都会触发（例如 `\x`、`\t`、`\U`）。
    - 从 a5af889 起，单独一个 `\r` 也会触发。
- 复现：`node probes/q1-perf.mjs tip 200000` 与 `node probes/q1-perf2.mjs <ver>`。

| 输入（约 200k 字符） | tip | v6.19.0 |
|---|---|---|
| benign 英文 | 8.5 ms | 6.9 ms |
| `PGP 头\nComment:` + 空格×N + `\x` | **48,893 ms** | 1.7 ms |
| 同上，结尾改为 `\rx` | **48,901 ms** | 1.6 ms |
| 转义换行 + tab 串 + `\t` | **46,068 ms** | 1.7 ms |

- 翻倍比：`bs` 形态 25k→50k 为 756→3,038 ms（×4.0，二次方）。
- 各版本对照：
  - 4f00c32 和 f840a79 只在 `\r` 形态上慢（50k 时 2,714 / 2,769 ms），`\x` 形态是 0 ms。反斜杠形态由 6b4dab2 的 `[^\r\n\\]` 引入。
  - v6.19.0 与 v6.18.0 两种形态都 ≤ 1 ms，所以相对已发布版本是回归。
- 触达路径：
  - `hook.mjs:3038` 在 UserPromptSubmit 上同步执行 `scrubSecrets(promptText)`，该 hook 的 `timeout` 是 2/5 秒（`hooks/hooks.json:118,123`）。约 30–50k 字符的构造 prompt 就会让 hook 被杀、这条 prompt 行丢失。
  - `lib/save-observation.mjs:193` 在 mem_save 正文上执行 `scrubSecrets(content)`，200k 字符会让 MCP 服务器同步卡住约 49 秒。
- 测试缺口：`tests/secret-scrub-linear.test.mjs` 的形态表里没有「头部行内的空白串」这种形态，所以没有抓到。
- 修复方向：去掉头部行分支后面的 `[ \t]*`（值类已经包含空白），或者改成 `(?=([^\r\n\\]*))\1` 这种原子化写法。修完后要保留 m4 那个测试（见下文 claims 表），它依赖「在反斜杠处停止」。

## P2

### P2-1 headerless tail 模式：最后一行数据短于 16 字符的 PGP 私钥尾部被整段存储
- 位置：`secret-scrub.mjs:224`，结构是 `(long BR)+ (short BR)? END?`。
- 机制：
  - armored PGP 在 END 之前总有一行 `=XXXX` 的 CRC 校验行（5 字符）。
  - 如果最后一行 base64 数据也短于 16 字符，就会出现连续两行短行，运行到不了 END，整段按原样返回。
  - 按行长近似均匀估计，约 15/64 的密钥会落在这个情况里（估算，未实测分布）。
- 复现：`node probes/q1-cases.mjs` 中的 `PGP tail, short last + checksum` 用例。

| 版本 | 结果 |
|---|---|
| tip / mid | 4 段密钥材料全部保留 |
| parent f840a79 | `***PEM_KEY***` |
| v6.19.0 / v6.18.0 | 全部保留 |

- 回归判断：相对 v6.19.0 不是回归；相对未发布的 parent 是回归，由 4f00c32 的 `{16,}` + 「只允许一行短行」引入。
- 对 contract「never keep a private key's material」来说，这是一个仍然开着的缺口。
