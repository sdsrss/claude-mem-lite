### F1 (P2, P1 if this nesting counts as a real shape): PHP/Gson/.NET JSON held in a JSON string written by .NET or Gson still stores a value v6.30.13 erased
secret-scrub.mjs:1630 (`inBody = valueTokens(reencode(decoded))`), and the comment at 1583-1586.
At an outer literal, `encoded` holds the inner literals the way the inner level REWROTE them, with `\/` decoded to `/`
and the word joined. `decoded` holds them as they were written, so `reencode(decoded)` spells the inner `\/` as `\\/`,
and the word stays split. A joined word the inner rewrite produced is "not in the body" at the outer level, so the
outer level keeps it, even when the outer patterns (v6.30.13's reading) erased it. The inner level keeps it too when
its own run-on stopped earlier. That happens when the outer encoder hides a stop character that the inner encoder writes
as is: .NET writes `"` as `\u0022`, Gson writes `'` as `\u0027`. So the delta's sentence "Both sides are compared as the rewritten literal is encoded" does not hold
one level up. The trace (`repro/nested-join-trace.mjs`) shows: depth 1 `inKept=true -> KEPT`, depth 0
`inKept=false inBody=false -> KEPT`.
