**R2-1 P2, regression vs v6.31.0: readRegularText reads any regular file to EOF, so a sparse file above the project fills memory.**
- Where: claudemd.mjs:284-296.
- Claude Code skips instruction files over 4,194,304 bytes. The bundle prints "not a regular file or exceeds ${PY} byte limit" with PY=4194304.
- The sync reads these files whole, on every session: CLAUDE.md and CLAUDE.local.md in every directory above the project, and the detail doc beside a block. Anyone who can write /tmp can plant one, the same attacker as F1.
- `probes/p3-sparse-above.sh <tree> <sizes>`, with a 6 GiB data cap:

| Tree | Size | Time | maxRSS |
|---|---|---|---|
| cand | 1 GiB | 550 ms | 1078 MB |
