Oracles per trial (trial.mjs):
(a) Named: every truth row that is absent from the repaired store, or differs there, must be covered by an output line that names its table as damaged or unreadable, by a "without it" line, or by its id.
(b) Intact: every truth row that `SELECT rowid,* FROM t WHERE rowid=?` returns byte-identical from the damaged store as found (read on a copy, with writable_schema when the schema does not parse) must be in the repaired store unchanged.
(c) A refusal leaves the main file and -wal sha1 unchanged.
(d) The repaired store passes integrity_check.
(e) No temporary files are left.

A row whose bytes changed while SQLite still reads it without error, and which no integrity_check message names, is counted separately as "undetectable" and is not reported as a defect.

## 1. P1 — Rows lost or garbled in a table are not named when one of its indexes also has a structural problem

`tableDamage` (lib/db-salvage.mjs:146-191) drops every integrity_check line that matches AGREEMENT_RE (`row N missing from index`, `wrong # of entries in index`, …) whenever at least one non-agreement problem exists (:165). It then attributes each structural problem to an index root (:186) and returns null. So the table is not "damaged". At :814 (`if (!acc.damaged && !acc.mainDamaged) acc.missing = [];`) the rowids that its other indexes list, and that no read returned, are then thrown away too. Agreement lines are the only evidence of table damage that is structurally valid: a stale (lost-write) leaf, or changed payload bytes. Any structural problem on an index page of the same table silences them.

## 2. P1 — Intact rows dropped: the exponential search skips the whole rowid range

`nextReadable` (lib/db-salvage.mjs:198-233) probes `rowid > x` for `x = bad + d`, with `bad = x` and `d` doubling each step (:212-221). When the scan fails before reading any row, `after` = MIN_ROWID-1. The probes are then MIN+2^k-2: …, -2, then MAX-1 and MAX. No probe lands in 1..N. If the seeks past MAX also fail (the rightmost leaf or right-child pointer is damaged), it returns null at :219 and the pass ends. The descending pass mirrors this. Only rows that a readable full index lists are then looked up. deferred_work has only partial indexes, and an index whose definition sits on a damaged sqlite_master page is not listed at all.

Repro A: one damaged page, 8 bytes. The deferred_work root (interior page 60) gets its right-child pointer (offset 8) and its first cell's child pointer := 0x41414141 (pristine2).
```
  ⚠ SQLite's integrity check fails: Tree 60 page 60 cell 0: invalid page number 1094795585 … (and 1 more)
  ⚠ deferred_work: 27 row(s) SQLite could not read with the log were taken from the database file without it, …
  ⚠ deferred_work: some of its pages are damaged (Tree 60 page 60 cell 0: invalid page number 1094795585), so rows on them may be missing, or hold damaged values.
  ⚠ deferred_work: 24 row(s) an index lists could not be read (ids 1, 7, 10, 13, 19, 22, 25, 31, 34, 37 and 14 more).
  ✓ Copied 6025 rows …
exit=0
  check: deferred_work pre-damage rows 410 | absent or different after repair 331 | of those, returned intact by SELECT ... WHERE rowid=? on the store as found 239 (ids 48,50,51,52,53)
```
The 7 middle leaves are intact. The output tells the user the rows are on damaged pages.

Repro B: the first and last deferred_work leaves' headers zeroed in their log frames. 54 rows that SQLite returns intact with their log values are replaced by older main-file versions; the log updated status to 'done'. The control, two damaged middle leaves, drops 0 intact rows.
```

```

Repro C (random plant 3-532): user_prompts root interior (64 bytes 0x41 at offset 7 in its log frame) plus one sqlite_master leaf. 196 user_prompts rows (802-1000) are returned intact by id, and the repaired store holds none of them. `SELECT … WHERE rowid=802` on the store as found returns the row. Seeks for `rowid > 100` and `rowid > 800` succeed; seeks for `rowid > -2` and `rowid > 2000` fail.

Population: a table whose leftmost and rightmost paths are both damaged and none of whose full indexes is readable. One interior page whose header and first cell pointer are hit (bytes 8-11 are the right-child pointer) is enough. With full indexes intact the rows are recovered by index lookups: 5 table roots tried, 0 dropped.

## 6. P2 — Disk full during the write-back changes the -wal and deletes the kept copy

An LD_PRELOAD shim (enospc.c) returns ENOSPC once 3,000,000 bytes have been written to `claude-mem-lite.db-wal`. The free-space pre-check passed.
```
  ✗ The disk filled up while writing into <dir>/claude-mem-lite.db; the database is as it was. Free some space and run repair-db again.
exit=1
main 4b435d44d9ea -> 4b435d44d9ea ; wal cebf2359f4ca (2595632 B) -> f913787e6ec0 (5595016 B)
files left: claude-mem-lite.db claude-mem-lite.db-shm claude-mem-lite.db-wal   (the .damaged-* copy was removed)
cmp: the first 2,595,632 bytes are identical
```
The backup's spilled, uncommitted frames stay after the last commit frame. The store reads the same, but the contract requires the -wal to be byte for byte as found. The `finally` at :573-576 deletes the byte copy, so after this refusal no byte-exact copy exists.

A related risk, reasoned and not run: a log whose checksum chain breaks mid-file hides its tail. The backup appends at mxFrame+1, so it overwrites those hidden frames; with the copy deleted on failure, they are gone.

import Database from 'better-sqlite3';
import { readFileSync, writeFileSync, existsSync, openSync, writeSync, closeSync } from 'node:fs';
import { createHash } from 'node:crypto';
export const sha = (p) => (existsSync(p) ? createHash('sha1').update(readFileSync(p)).digest('hex') : null);
export const jsonRow = (r) => JSON.stringify(r, (_, v) => (typeof v === 'bigint' ? `${v}` : v));
export function tablesOf(db) {
  const virt = db.prepare(`SELECT name FROM pragma_table_list WHERE schema='main' AND type='virtual'`).pluck().all();
  return db.prepare(`SELECT name FROM pragma_table_list WHERE schema='main' AND type='table'`).pluck().all()
    .filter((t) => !t.startsWith('sqlite_') && t !== 'schema_version' && !virt.some((v) => t.startsWith(v + '_')));
}
/** {table: {rowid: json}} */
export function dump(p) {
  const db = new Database(p, { readonly: true, fileMustExist: true });
  try {
    const out = {};
    for (const t of tablesOf(db)) {
      out[t] = {};
      for (const r of db.prepare(`SELECT rowid AS __rowid, * FROM "${t}" ORDER BY rowid`).safeIntegers(true).all())
        out[t][String(r.__rowid)] = jsonRow(r);
    }
    return out;
  } finally { db.close(); }
}
export function walChecksum(buf, s0, s1, be) {
  for (let i = 0; i + 7 < buf.length; i += 8) {
    const a = be ? buf.readUInt32BE(i) : buf.readUInt32LE(i);
    const b = be ? buf.readUInt32BE(i + 4) : buf.readUInt32LE(i + 4);
    s0 = (s0 + a + s1) >>> 0;
    s1 = (s1 + b + s0) >>> 0;
  }
  return [s0, s1];
}
export function walFrames(walPath) {
  const wal = readFileSync(walPath);
  const ps = wal.readUInt32BE(8);
  const frames = [];
  for (let o = 32; o + 24 + ps <= wal.length; o += 24 + ps) frames.push({ o, pg: wal.readUInt32BE(o), commit: wal.readUInt32BE(o + 4) });
  return { ps, frames };
}
/** Apply fn(pageBuf) to frame index fi and re-sign the chain. */
export function plantWalFrame(walPath, fi, fn) {
  const wal = Buffer.from(readFileSync(walPath));
  const be = wal.readUInt32BE(0) === 0x377f0683;
  const ps = wal.readUInt32BE(8);
  const frames = [];
  for (let o = 32; o + 24 + ps <= wal.length; o += 24 + ps) frames.push({ o });
  const f = frames[fi];
  fn(wal.subarray(f.o + 24, f.o + 24 + ps));
  let [s0, s1] = walChecksum(wal.subarray(0, 24), 0, 0, be);
  for (const fr of frames) {
    [s0, s1] = walChecksum(wal.subarray(fr.o, fr.o + 8), s0, s1, be);
    [s0, s1] = walChecksum(wal.subarray(fr.o + 24, fr.o + 24 + ps), s0, s1, be);
    wal.writeUInt32BE(s0, fr.o + 16);
    wal.writeUInt32BE(s1, fr.o + 20);
  }
  writeFileSync(walPath, wal);
}
export function plantMain(p, pageno, ps, fn) {
  const buf = Buffer.from(readFileSync(p));
  fn(buf.subarray((pageno - 1) * ps, pageno * ps));
  writeFileSync(p, buf);
}
export function pageMap(p) {
  const db = new Database(p, { readonly: true });
  try {
    return db.prepare(`SELECT name, pageno, pagetype FROM dbstat ORDER BY pageno`).all();
  } finally { db.close(); }
}

### shim/enospc.c
```
// LD_PRELOAD: ENOSPC on writes to a file whose path ends with $ENOSPC_SUFFIX once this process has
// written $ENOSPC_BUDGET bytes to such files.
#define _GNU_SOURCE
#include <dlfcn.h>
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/types.h>
static long long used = 0;
static int matches(int fd) {
  const char *suf = getenv("ENOSPC_SUFFIX");
  if (!suf) return 0;
  char link[64], path[4096];
  snprintf(link, sizeof link, "/proc/self/fd/%d", fd);
  ssize_t n = readlink(link, path, sizeof path - 1);
  if (n <= 0) return 0;
  path[n] = 0;
  size_t ls = strlen(suf);
  return (size_t)n >= ls && strcmp(path + n - ls, suf) == 0;
}
static int over(int fd, size_t count) {
  if (!matches(fd)) return 0;
  long long budget = atoll(getenv("ENOSPC_BUDGET") ? getenv("ENOSPC_BUDGET") : "0");
  if (used + (long long)count > budget) { if (getenv("ENOSPC_LOG")) fprintf(stderr, "[shim] ENOSPC fd=%d used=%lld\n", fd, used); return 1; }
  used += count;
  return 0;
}
ssize_t write(int fd, const void *buf, size_t count) {
  static ssize_t (*real)(int, const void *, size_t);
  if (!real) real = dlsym(RTLD_NEXT, "write");
  if (over(fd, count)) { errno = ENOSPC; return -1; }
  return real(fd, buf, count);
}
ssize_t pwrite(int fd, const void *buf, size_t count, off_t off) {
  static ssize_t (*real)(int, const void *, size_t, off_t);
  if (!real) real = dlsym(RTLD_NEXT, "pwrite");
  if (over(fd, count)) { errno = ENOSPC; return -1; }
  return real(fd, buf, count, off);
}
ssize_t pwrite64(int fd, const void *buf, size_t count, off_t off) {
  static ssize_t (*real)(int, const void *, size_t, off_t);
  if (!real) real = dlsym(RTLD_NEXT, "pwrite64");
  if (over(fd, count)) { errno = ENOSPC; return -1; }
  return real(fd, buf, count, off);
}

// Run the new doctor on damaged stores (specs from a fuzz jsonl whose premise failed); check bytes.
import { spawnSync } from 'node:child_process';
import { readFileSync, rmSync, existsSync, statSync } from 'node:fs';
import { join } from 'node:path';
import { sha } from './lib.mjs';
const [tree, pristine, jsonl, maxN] = process.argv.slice(2);
const specs = readFileSync(jsonl, 'utf8').trim().split('\n').map(JSON.parse).filter((r) => r.premise === 'fails').map((r) => r.spec).slice(0, Number(maxN));
let changed = 0, noFail = 0, n = 0;
for (const spec of specs) {
  const dir = join(pristine, '..', 'trials', 'doc-' + spec.id);
  spawnSync(process.execPath, ['plant.mjs', pristine, dir, JSON.stringify(spec)]);
  const p = join(dir, 'claude-mem-lite.db');
  const before = { m: sha(p), w: sha(p + '-wal') };
  const r = spawnSync(process.execPath, [join(tree, 'install.mjs'), 'doctor'], { encoding: 'utf8', env: { ...process.env, CLAUDE_MEM_DIR: dir }, timeout: 120000 });
  const after = { m: sha(p), w: sha(p + '-wal') };
  n++;
  const dbLines = r.stdout.split('\n').filter((l) => /Database|FTS5/.test(l));
  const hasFail = dbLines.some((l) => /✗/.test(l));
  if (!hasFail) { noFail++; console.log('NO ✗', spec.id, JSON.stringify(spec.damage), dbLines.join(' / ').slice(0, 300)); }
  if (before.m !== after.m || before.w !== after.w) { changed++; console.log('CHANGED', spec.id, JSON.stringify(spec.damage), JSON.stringify({ before, after })); }
  else rmSync(dir, { recursive: true, force: true });
}
console.log(JSON.stringify({ n, changed, noFail }));

### shim/openlog.c
```
// LD_PRELOAD: log opens (with flags) and writes of files whose basename is exactly $OL_NAME or $OL_NAME-wal.
#define _GNU_SOURCE
#include <dlfcn.h>
#include <fcntl.h>
#include <stdarg.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <unistd.h>
#include <sys/types.h>
static double now(void) { struct timespec t; clock_gettime(CLOCK_MONOTONIC, &t); return t.tv_sec + t.tv_nsec / 1e9; }
static int target(const char *path) {
  const char *n = getenv("OL_NAME"); if (!n || !path) return 0;
  const char *b = strrchr(path, '/'); b = b ? b + 1 : path;
  size_t ln = strlen(n);
  return strcmp(b, n) == 0 || (strncmp(b, n, ln) == 0 && strcmp(b + ln, "-wal") == 0);
}
static void logit(const char *what, const char *path, int flags) {
  char buf[600]; int k = snprintf(buf, sizeof buf, "[ol %.6f pid=%d] %s %s flags=%s\n", now(), getpid(), what, path, (flags & O_RDWR) ? "RDWR" : (flags & O_WRONLY) ? "WRONLY" : "RDONLY");
  static ssize_t (*w)(int, const void *, size_t); if (!w) w = dlsym(RTLD_NEXT, "write");
  static int (*o)(const char *, int, ...); if (!o) o = dlsym(RTLD_NEXT, "open");
  int fd = o(getenv("OL_LOG"), O_WRONLY | O_APPEND | O_CREAT, 0644); if (fd >= 0) { w(fd, buf, k); close(fd); }
}
#define OPENF(name) int name(const char *path, int flags, ...) { static int (*real)(const char *, int, ...); if (!real) real = dlsym(RTLD_NEXT, #name); mode_t m = 0; if (flags & O_CREAT) { va_list a; va_start(a, flags); m = va_arg(a, int); va_end(a); } int fd = real(path, flags, m); if (fd >= 0 && target(path) && (flags & (O_RDWR | O_WRONLY))) logit(#name, path, flags); return fd; }
OPENF(open)
OPENF(open64)
#define OPENATF(name) int name(int dfd, const char *path, int flags, ...) { static int (*real)(int, const char *, int, ...); if (!real) real = dlsym(RTLD_NEXT, #name); mode_t m = 0; if (flags & O_CREAT) { va_list a; va_start(a, flags); m = va_arg(a, int); va_end(a); } int fd = real(dfd, path, flags, m); if (fd >= 0 && target(path) && (flags & (O_RDWR | O_WRONLY))) logit(#name, path, flags); return fd; }
OPENATF(openat)
OPENATF(openat64)
static int fdtarget(int fd, char *out) { char l[64]; snprintf(l, sizeof l, "/proc/self/fd/%d", fd); ssize_t n = readlink(l, out, 4095); if (n <= 0) return 0; out[n] = 0; return target(out); }
static void wlog(int fd) { char p[4096]; if (fdtarget(fd, p)) logit("WRITE", p, O_RDWR); }
ssize_t write(int fd, const void *buf, size_t c) { static ssize_t (*real)(int, const void *, size_t); if (!real) real = dlsym(RTLD_NEXT, "write"); if (fd > 2) wlog(fd); return real(fd, buf, c); }
ssize_t pwrite(int fd, const void *buf, size_t c, off_t o) { static ssize_t (*real)(int, const void *, size_t, off_t); if (!real) real = dlsym(RTLD_NEXT, "pwrite"); wlog(fd); return real(fd, buf, c, o); }
ssize_t pwrite64(int fd, const void *buf, size_t c, off_t o) { static ssize_t (*real)(int, const void *, size_t, off_t); if (!real) real = dlsym(RTLD_NEXT, "pwrite64"); wlog(fd); return real(fd, buf, c, o); }
