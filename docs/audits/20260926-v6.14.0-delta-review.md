`lib/bash-file-targets.mjs:350-438` (`scriptTargets` :375-438, `rowHeadRe` :435, `BINDING_RE` :368)

  - `import pathlib; p = pathlib.Path('lib/x.mjs'); p.write_text(…)`: **new W=[]**. BINDING_RE only accepts a bare `Path(`.
  - `p = ROOT / 'lib/x.mjs'; p.write_text(…)`: new W=[].
  - `files=['a.mjs','b.mjs']; for f in files: open(f,'w')`: new W=[].
  - `['a.mjs','b.mjs'].forEach(f=>fs.writeFileSync(f,…))`: new W=[].
  - `fs.writeFileSync(path.resolve('lib/x.mjs'),…)`: new W=[].
  - `const w = f => fs.writeFileSync(f,'x'); w('lib/x.mjs')`: new W=[].
  - `ruby -e "File.write('lib/x.rb','x')"`: new W=[].
- Transcript replay (`replay-writes.mjs`, 62 main transcripts, 10383 Bash commands, 2026-09-26 ~18:20Z):
  - Commands with any write: 3574 → 3503. 71 lost every write, 342 lost some.
  - 63 of the 71 had lost a project path. By shape: **python tuple edit table 27**, string concatenation 13, pathlib module form 4, list-variable loop 2, other 17. I hand-read #8, #14 and #55: all three are real multi-file patches.

- Consequences are the ones P2-1 listed, now in the other direction:

### P2-B: the prefilter regex goes superlinear on tab-heavy commands
`scripts/pre-tool-recall-bash.sh:74` (`start="(^|;|&&|\\|\\||\\(|\\\\n|\\\\t)…"`) together with `wrap`'s `-[^[:space:]]+` / `[0-9]+…` at :73.
- Repro (`perf3.mjs`): `python3 analyze.py <<'EOF'` followed by a tab-separated numeric matrix with negative values, run through the shipped regexes (only the final node hand-off replaced by `echo PASS`).

  | payload | 207dc38 | d9ea38d |
  |---|---|---|
  | 47 KB | 15 ms | **925 ms** |
  | 149 KB | 27 ms | **8785 ms** |

  The Bash matcher's hook timeout is **3 s** (`hooks/hooks.json`). Synthetic `\t-a` × 20000 (80 KB) reads 26 ms → 6246 ms.
- Cause: every JSON `\t` is a command-start candidate. The wrap chain (`-0.143\t-0.286\t…`) then re-scans the rest of the line from each one.
- Fix, measured: drop `|\\\\t` from `start`. A tab after `\n` / `;` is already matched by `ws`. The patched copy reads 20 ms (47 KB) and 65 ms (149 KB).
- I reasoned, but did not run, that the new test case `'echo hi\n\tcat lib/m.mjs'` stays covered by `\n` + `ws`.
- How often a real command has this shape is unmeasured. I did not record per-command times in the 10383-command replay.
