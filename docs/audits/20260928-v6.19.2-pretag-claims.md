- 出处对应不准：
  - P3-A 是 **body 之后**的缩写词，不是 header 之后；
  - P3-C 是 header 值跨过 `\\`、`\"`、`\t` 转义吃掉后面的 JSON 字段（round3 文档 P3-C），机制与「下一行开头的词」不同。修复它的规则是「escaped text 中未转义的引号结束字符串 / 真实换行下反斜杠不算换行」，不是「整行 base64」。

- 40 字符以上的 token 单独位于 header 下仍会被擦，两棵树都如此，与注释中「16-39」的界限一致：
  - `/usr/local/etc/ssh/keys/somethinglongername`；

  - 40 位数字。
