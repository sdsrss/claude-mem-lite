## 5. 两个杠杆（定义固定）

**S2(a) 每会话 pretool 上限**
- 每个会话按时间顺序只保留前 N 个 pretool 注入块，从第 N+1 个起整块去掉。
- N 的公式事先固定：窗口内纳入会话的 pretool 块数中位数，向下取整，最小为 3。
- 被去掉的块 = 每个会话从第 N+1 个起的块。块的抽取与字节计算都用 `injection-budget.mjs` 的同一遍历。

**S2(b) 只给有 lesson、importance ≥ 2 的 bugfix / decision**
- 对 pretool 块里每一个记忆 id：只要运行时只读副本里它的 type 不属于 {bugfix, decision}，或 importance < 2，或 lesson 为空或 `none`，
  就去掉这一行；一个块里的行全部被去掉，就整块去掉。
- `E#` 开头的事件 id 按 `events` 表的 `event_type` 和 importance 判断；`events` 没有 lesson 列，以 body 非空代替。
- 已知偏差：importance 被五个写入方改写（CLAUDE.md），这里用的是运行时的值，不是注入那一刻的值。

## 6. 盲评与判定

**样本**：三组，每组按 sha1(会话 id + 块序号) 确定性抽 30 个，不足 30 个就全取。
- A = S2(a) 去掉的块；
- B = S2(b) 整块去掉的块；
- C = 两个杠杆都保留的块（对照）。

一个块同时属于 A 和 B 时，两组都计入，但评审只看一次，两组共用这一条标注。

**评审**：
- 每个样本附上最近一条用户消息、触发调用、注入原文、之前 2 步和之后 6 步的操作（格式与 R3 §4.3 相同）。
- 去掉组标签、打乱顺序，交给不知道假设的子代理；每个子代理最多评 60 个。
- 标签五选一，与 R3 §4.3 相同：APPLICABLE / TOPICAL / IRRELEVANT / MISLEADING / UNCLEAR。
- 评审输出原样保存，包括每个样本的理由；报告 Wilson 95% 区间。

**判定**（两个杠杆分别判）。采纳的条件是以下全部成立：
1. 去掉组 APPLICABLE ≤ 2/30（样本不足 30 时按比例，即 ≤ 6.7%）；
2. 去掉组的 APPLICABLE 数不高于对照组 C；
3. 杠杆去掉的 pretool 字节 ≥ pretool 总字节的 30%（`injection-budget.mjs` 投影）。低于这个比例，不值一次 L3。

采纳之后：写 L3 规格并请求授权，不自行实现（改的是已发布插件的默认注入行为）。
不采纳：读数写进本文和 `docs/measurement/findings.md`，没有新数据不再提出。

**功效限制**（照抄 R3 计划 §5）：真实适用率为 10% 时，30 个样本里出现 ≤ 2 个的概率约 41%。这条规则挡的是"成片去掉切题内容"，
不能证明去掉的部分毫无价值。

## 7. 前提检查（判定之前先跑）

- 纳入会话 ≥ 30；pretool 块 ≥ 300；A、B 两组可抽样本各 ≥ 20。
- 任一条不满足：不做判定，只报 Q0，并把顺延后的窗口记进延期项。
